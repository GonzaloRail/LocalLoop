1. Acceso y creación de cuenta
Mockup 01 — Landing / Inicio
Pantalla inicial de LocalLoop.
Debe mostrar:

Explicación breve: “Marketing basado en resultados”.
Botón Crear cuenta.
Botón Iniciar sesión.

Mockup 02 — Seleccionar tipo de cuenta
El usuario decide cómo utilizará LocalLoop:
Soy un negocio
Crea campañas y paga por conversiones verificadas.
Soy un promotor
Promociona campañas y gana recompensas por conversiones.
Cada opción lleva al registro correspondiente.

Mockup 03 — Registro de Negocio
Formulario para crear la cuenta empresarial.
Campos:
Nombre del negocio.
Correo electrónico.
Contraseña.
Categoría.
Descripción.
Teléfono.
Dirección, si corresponde.
Wallet Stellar: botón “Conectar con Freighter”.
Al pulsar “Conectar con Freighter”:
Se abre la extensión de Freighter en el navegador.
Freighter muestra una solicitud de conexión de LocalLoop.
El usuario selecciona la cuenta Stellar que desea utilizar.
El usuario confirma “Connect” en Freighter.
LocalLoop recibe únicamente la dirección pública Stellar de la cuenta.
El registro muestra la wallet conectada, por ejemplo: G...8XK2.
La dirección queda asociada a la cuenta del negocio.
Importante: LocalLoop no solicita ni almacena la contraseña de Freighter, clave privada o frase de recuperación. Freighter se encarga de proteger las claves y de firmar las operaciones cuando el usuario las autoriza.
Botón: Crear cuenta


Mockup 04 — Registro de Promotor
Formulario para crear la cuenta.
Campos:
Nombre completo.
Correo.
Contraseña.
Teléfono opcional.
Wallet Stellar: botón “Conectar con Freighter”.
Al pulsar “Conectar con Freighter”:
Se abre Freighter.
Freighter solicita autorización para conectar la wallet con LocalLoop.
El usuario selecciona su cuenta Stellar.
Confirma la conexión.
LocalLoop recibe la dirección pública Stellar.
La dirección queda vinculada al perfil del promotor.
Esta wallet será posteriormente utilizada para recibir las recompensas en USDC cuando finalice la campaña y se ejecute la liquidación mediante Soroban y Stellar.
Importante: LocalLoop nunca solicita la frase de recuperación ni la clave privada. Las operaciones que requieran firma se autorizan directamente desde Freighter.
Botón: Crear cuenta

Mockup 11 — Crear campaña: Acción y validación
Esta pantalla es muy importante.
El negocio debe explicar exactamente qué cuenta como conversión.
Campo:
¿Qué acción debe realizar el cliente?
Ejemplo:
Compra de una entrada.
Luego:
¿Cómo se atribuirá la conversión?
Opciones:
Código de referido.
QR.
Enlace de referencia.
Código + comprobante.
Otro mecanismo.
Después:
¿Qué identificará la operación?
Ejemplo:
Número de entrada.
Y finalmente:
Condiciones de la conversión
Ejemplo:
“La compra debe realizarse durante la vigencia de la campaña y debe estar asociada al código del promotor.”
Esto evita que posteriormente el usuario no sepa cómo funciona la campaña.

11. FLUJO COMPLETO PARA FIGMA
En Figma puedes organizarlo literalmente como dos grandes recorridos:
RECORRIDO 1 — NEGOCIO
Landing
→ Registro
→ Seleccionar Negocio
→ Crear cuenta
→ Login
→ Dashboard
→ Crear campaña
→ Información
→ Recompensa
→ Acción y validación
→ Resumen
→ Financiar con Stellar
→ Publicar
→ Mis campañas
→ Detalle
→ Conversiones
→ Cierre
→ Liquidación con Soroban/Stellar
→ Confirmación
→ Historial

RECORRIDO 2 — PROMOTOR
Landing
→ Registro
→ Seleccionar Promotor
→ Crear cuenta
→ Login
→ Dashboard
→ Explorar campañas
→ Detalle de campaña
→ Participar
→ Código + QR
→ Promocionar
→ Mis campañas
→ Conversiones
→ Ganancias
→ Estado de cuenta
→ Historial de transacciones
→ Perfil + Wallet

Y el recorrido que conecta ambos
Este es el que debes representar especialmente bien en el prototipo:
Negocio crea campaña
↓
Financia campaña
↓
Promotor se inscribe
↓
LocalLoop genera DIEGO82
↓
Promotor comparte código/QR
↓
Cliente realiza la acción definida
↓
Conversión registrada
↓
Campaña finaliza
↓
Negocio confirma conversiones
↓
Soroban ejecuta liquidación
↓
Stellar distribuye USDC
↓
Promotor ve la ganancia en su estado de cuenta
Ese es el flujo central de LocalLoop. Si construyes estos 31 mockups, no necesitas inventar pantallas adicionales para el MVP; tienes cubiertos registro, autenticación, operación del negocio, operación del promotor, campañas, códigos, conversiones, cierre, liquidación, ganancias y la parte de Stellar/Soroban.
